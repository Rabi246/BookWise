# BookWise

**An AI-powered book tracking and recommendation web app.** Search any book, save it to your personal library, rate it, and get personalized recommendations, spoiler-free summaries, and character relationship breakdowns generated by an LLM.

Built as a team project for **CS 3220 (Web & Internet Programming)** at Cal State LA, Fall 2025.

## Features

- **Book search**: live search powered by the **Google Books API**, with covers, authors, and descriptions
- **Personal library**: add and remove books from your own "My Books" shelf, saved to a MySQL database
- **Ratings**: rate the books in your library
- **AI recommendations**: analyzes your saved books and suggests 5–7 new reads, each with an explanation, why it fits your taste, and a confidence score
- **AI book summaries**: spoiler-free overviews of any book
- **Character relationships**: AI-generated breakdowns of how the main characters connect
- **Accounts**: register, log in/out, and password reset flow

## Tech Stack

| Layer | Tech |
|---|---|
| Backend | Java 25, Spring Boot 3.5, Spring Data JPA |
| Frontend | JTE templates, HTML, CSS, JavaScript |
| AI | Spring AI (OpenAI-compatible client via OpenRouter, GPT model) |
| Data | MySQL, Google Books API |
| Build | Maven |

## How It Works

```
Browser ──► Spring Boot controllers ──► Services ──► MySQL (users, books, library, ratings)
                    │                       │
                    │                       └──► LLM via Spring AI (recs, summaries, relationships)
                    └──► Google Books API (search + book metadata)
```

The app follows an MVC structure: `controller/` handles routes, `service/` builds prompts and calls the LLM, and `model/` + `repository/` map users, books, library entries, and ratings to the database through JPA.

## Running Locally

**Requirements:** Java 25, a MySQL database, and an [OpenRouter](https://openrouter.ai) API key.

1. Clone the repo
   ```bash
   git clone https://github.com/Rabi246/BookWise.git
   cd BookWise/BookWise
   ```
2. Set your environment variables
   ```bash
   export OPENAI_API_KEY=your_openrouter_key
   export DB_URL=jdbc:mysql://localhost:3306/bookwise
   export DB_USERNAME=your_db_user
   export DB_PASSWORD=your_db_password
   ```
3. Run it
   ```bash
   ./mvnw spring-boot:run
   ```
4. Open http://localhost:8080
