# BookWise

**An AI-powered book tracking and recommendation web app.** Search any book, save it to your personal library, rate it, and get personalized recommendations, spoiler-free summaries, and character relationship breakdowns generated by an LLM.

Built as a team project for **CS 3220 (Web & Internet Programming)** at Cal State LA, Fall 2025, and later refactored and maintained by me.

---

## Features

- **Book search**: search millions of books through the **Google Books API**, with covers, authors, and descriptions
- **Personal library**: add and remove books from your own "My Books" shelf, saved to a MySQL database
- **Ratings**: rate the books in your library
- **AI librarian chat**: describe what you're in the mood for and get conversational recommendations, with matching book cards pulled from Google Books

## How It Works

```
Browser ──► Spring Boot controllers ──► Services ──► MySQL (users, books, library, ratings)
                    │                       │
                    │                       └──► LLM via Spring AI (recs, summaries, relationships)
                    └──► Google Books API (search + book verification, server-side)
```

The app follows an MVC structure: `controller/` handles routes, `service/` builds prompts and calls the LLM, and `model/` + `repository/` map users, books, library entries, and ratings to the database through JPA.

When the AI recommends books, it returns a structured JSON list alongside its chat reply. The backend parses that list and verifies each title against Google Books, so every recommendation card shows a real book with a real cover. All Google Books requests go through the backend, so the API key never reaches the browser.

## Running Locally

**Requirements:** Java 25, a MySQL database, an [OpenRouter](https://openrouter.ai) API key, and a [Google Books API](https://developers.google.com/books) key.

1. Clone the repo
   ```bash
   git clone https://github.com/Rabi246/BookWise.git
   cd BookWise/BookWise
   ```
2. Start a MySQL database (or use your own)
   ```bash
   docker run -d --name bookwise-mysql -e MYSQL_ROOT_PASSWORD=your_db_password -e MYSQL_DATABASE=bookwise -p 3306:3306 mysql:8
   ```
3. Copy the example env file and fill in your keys
   ```bash
   cp .env.example .env
   ```
4. Run it
   ```bash
   ./mvnw spring-boot:run
   ```
   On Windows, use `mvnw.cmd spring-boot:run`.
5. Open http://localhost:8080 and register an account

Database tables are created automatically on first run.

## Configuration

All secrets and environment-specific settings are loaded from a `.env` file (gitignored) via Spring Boot's `spring.config.import`. See [`.env.example`](BookWise/.env.example) for the full list:

| Variable | Description |
|---|---|
| `OPENAI_API_KEY` | OpenRouter API key |
| `GOOGLE_BOOKS_API_KEY` | Google Books API key |
| `DB_URL` | JDBC URL for MySQL |
| `DB_USERNAME` | Database username |
| `DB_PASSWORD` | Database password |
